# JustTalk для iOS — установка для тестирования

JustTalk — офлайн-диктовка: нажимаете Action Button, говорите, нажимаете ещё раз,
распознанный текст оказывается в буфере обмена. Распознавание (Qwen3-ASR) идёт
на самом iPhone, интернет нужен только один раз — скачать модель.

Приложения нет в App Store. Его ставят из исходников через Xcode со своим
бесплатным Apple ID. Такая установка живёт 7 дней, потом её нужно повторить
(см. «Через 7 дней»).

## Что нужно

- **Mac** с **Xcode 27.1** или новее (бесплатно в App Store).
- **iPhone с iOS 27** или новее. Action Button есть на iPhone 15 Pro / 15 Pro Max и новее;
  на других моделях диктовку можно запускать из приложения или из «Быстрых команд».
- **Apple ID** — подойдёт обычный, платная подписка разработчика не нужна.
- **USB-кабель** iPhone ↔ Mac.
- **Место:** около 1 ГБ на Mac (зависимости сборки) и 1–3 ГБ на iPhone (модель).

## 1. Исходники

Распакуйте полученный архив (или клонируйте репозиторий) в любую папку,
например `~/JustTalk`. Внутри должен лежать `JustTalk.xcodeproj`.

## 2. Apple ID в Xcode

Xcode → Settings… (⌘,) → **Accounts** → «+» → **Apple Account** → войдите своим Apple ID.
В списке появится команда вида «Иван Иванов (Personal Team)».

## 3. Открыть проект и подождать зависимости

Откройте `JustTalk.xcodeproj` двойным щелчком. Xcode сам скачает пакет
`sherpa-onnx` (движок распознавания, ~650 МБ) — прогресс виден внизу левой панели
(«Resolving Package Graph» / «Fetching»). Дождитесь окончания.

## 4. Подпись — своя команда и свои идентификаторы

Это обязательный шаг: идентификатор `com.spirt.JustTalk` уже занят автором,
со своим Apple ID его использовать нельзя.

1. В левой панели щёлкните синюю иконку проекта **JustTalk** (самая верхняя строка).
2. В списке TARGETS выберите **JustTalk** → вкладка **Signing & Capabilities**:
   - галочка **Automatically manage signing** — включена;
   - **Team** — ваша «(Personal Team)»;
   - **Bundle Identifier** — замените `spirt` на что-то своё, например
     `com.ivanov.JustTalk`. Только латиница, цифры, точки и дефисы.
3. Выберите TARGET **JustTalkWidget** → **Signing & Capabilities**:
   - **Team** — та же;
   - **Bundle Identifier** — тот же, что у приложения, плюс `.widget`:
     `com.ivanov.JustTalk.widget`. Начало должно совпадать с идентификатором приложения
     буква в букву, иначе сборка не установится.

Таргеты JustTalkTests и JustTalkUITests трогать не нужно.

Если под Team появилась красная ошибка про идентификатор — придумайте другой
(он должен быть уникален во всём мире Apple) и повторите для обоих таргетов.

## 5. Подготовить iPhone

1. Подключите iPhone кабелем, разблокируйте, на вопрос «Доверять этому компьютеру?» — **Доверять**.
2. Включите **режим разработчика**: Настройки → Конфиденциальность и безопасность →
   **Режим разработчика** → включить → перезагрузка → после перезагрузки подтвердить «Включить».
   Если пункта нет — откройте Xcode с подключённым iPhone и выберите телефон
   как устройство запуска (шаг 6), пункт появится; затем вернитесь сюда.

## 6. Собрать и установить

1. Вверху окна Xcode, справа от названия схемы **JustTalk**, выберите свой iPhone
   (не симулятор).
2. Нажмите **▶** (или ⌘R). Первая сборка занимает несколько минут.
3. При первой установке iPhone не даст открыть приложение («Ненадёжный разработчик»).
   Откройте Настройки → Основные → **VPN и управление устройством** → ваш Apple ID →
   **Доверять**. Затем снова нажмите ▶ в Xcode.

После установки кабель и Xcode больше не нужны (до истечения 7 дней).
Если приложение запущено из Xcode, лучше остановить его (■) и дальше открывать
с экрана iPhone — под отладчиком поведение может отличаться.

## 7. Первый запуск

1. Откройте JustTalk → шестерёнка ⚙ → **Модель распознавания**:
   - **Qwen3-ASR 0.6B** (≈0,8 ГБ, рекомендуется) — быстрее;
   - **Qwen3-ASR 1.7B** (≈2,3 ГБ) — точнее, медленнее и требовательнее к памяти.

   Нажмите **Скачать** (лучше по Wi-Fi), дождитесь 100 %, отметьте модель галочкой
   («Выбрать»), если она не выбрана. Готово.
2. На главном экране нажмите **● Записать**, разрешите доступ к **микрофону**,
   скажите пару фраз, нажмите **Стоп и распознать**. Текст появится на экране.

   Это важно сделать именно в приложении: из фона (Action Button) iOS не может
   показать запрос на микрофон.

## 8. Быстрая команда и Action Button

iOS не разрешает фоновому приложению писать в буфер обмена, поэтому копирование
делает «Быстрая команда».

1. Откройте приложение **Команды** → «+» (новая команда).
2. Добавьте действие: поиск «JustTalk» → **Диктовка JustTalk**.
3. Добавьте второе действие: **Скопировать в буфер обмена** (на вход само подставится
   «Значение» из первого действия).
4. Назовите команду, например «JustTalk», сохраните.
5. Настройки → **Кнопка действия** → листайте до **Быстрая команда** → выберите «JustTalk».

## Как пользоваться

1. Нажмите Action Button — начинается запись (на Dynamic Island / экране блокировки
   появится индикатор JustTalk).
2. Говорите.
3. Нажмите Action Button ещё раз — запись остановится, через несколько секунд текст
   окажется в буфере обмена.
4. Вставьте текст в любом приложении (долгое нажатие на поле → «Вставить»).

Запись также можно остановить кнопкой в Live Activity. Длительность записи
ограничена (по умолчанию 5 минут, меняется в настройках), по достижении лимита
запись остановится и распознается сама.

Особенность: в момент старта записи команда очищает буфер обмена — это нормально.

## Через 7 дней

Подпись бесплатного аккаунта действует 7 дней. Потом приложение перестанет
открываться («недоступно»). Чтобы продлить: подключите iPhone, откройте проект
в Xcode, нажмите ▶. Скачанные модели и настройки сохранятся, если приложение
**не удалять** с телефона.

## Что проверить и о чём сообщить

- Запуск с Action Button, когда приложение **закрыто** (смахнуто из переключателя).
- Запуск, когда приложение открыто или свёрнуто.
- Длинная диктовка (1–3 минуты): качество и время распознавания.
- Модель 1.7B: скорость, нагрев, не вылетает ли приложение.
- Гаснет ли экран сам во время и после записи (без Xcode).
- Работа поверх музыки/подкаста и во время звонка.

При ошибке пришлите скриншот уведомления или экрана с текстом ошибки, модель
iPhone, версию iOS и шаги, которые к ней привели. Если приложение «неожиданно
завершило работу», полезен отчёт: Настройки → Конфиденциальность и безопасность →
Аналитика и улучшения → Данные аналитики → файл, начинающийся с `JustTalk`.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Xcode: «Failed to register bundle identifier» / «No profiles for …» | Идентификатор занят — смените его в обоих таргетах (шаг 4). |
| Xcode: «Embedded binary's bundle identifier is not prefixed …» | Идентификатор виджета должен начинаться с идентификатора приложения + `.widget`. |
| Xcode: «Missing package product 'SherpaOnnx'» | File → Packages → **Reset Package Caches**, дождаться загрузки, собрать снова. |
| iPhone нет в списке устройств | Разблокировать, «Доверять компьютеру», включить режим разработчика. Window → Devices and Simulators — подождать, пока Xcode подготовит устройство. |
| «Ненадёжный разработчик» | Настройки → Основные → VPN и управление устройством → Доверять. |
| «Модель не найдена» | Скачать модель в ⚙ и убедиться, что она отмечена галочкой. |
| Ошибка записи / нет звука | Настройки → JustTalk → Микрофон — включить. |
| Буфер пустой после диктовки | Проверить, что Action Button вызывает именно команду из шага 8, а не приложение напрямую. |
| «Превышен лимит приложений» | На бесплатном аккаунте не больше 3 своих приложений на устройстве — удалите другое, подписанное вашим Apple ID. |
